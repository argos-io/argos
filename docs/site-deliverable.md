# Argos 站点交付物需求

状态：需求澄清中。更新：2026-11-07。总体要求见 [需求总览](requirements.md)，另一套需求见 [管理端](management-system.md)。

## 1. 定位与已确认职责

站点交付物是管理端生成的最终成果，以源代码为核心。同一套源码支持 Cloudflare 和用户的标准 Node.js 环境；用户可以接手维护，也可以使用管理端提供的 Cloudflare 托管服务。

管理端永久仅供内部团队使用，不向客户交付或开放。客户获得站点交付物及约定的托管服务，使用站点自身的独立业务后台经营站点。

交付程序负责站点业务运行与开放 API，不包含生成站点或新插件的代码生成过程。新增插件由管理端生成或选择、纳入构建并发布后，才成为交付程序的一部分。

已确认交付物必须自带独立站点业务后台；插件除业务功能外，还向业务后台注册对应管理功能。详见 [站点业务后台](business-admin.md)。

交付物由固定版本核心、选定插件、主题及组装配置构成。操作人按需求编辑插件和主题，不修改核心；具体核心依赖与源码交接方式待设计。主题是一类插件，负责页面、布局、视觉和业务能力的呈现，详见 [主题与操作边界](themes.md)。

## 2. 运行与扩展要求

- 最小运行时通过插件扩展业务功能，保持核心尽量小。
- 插件构建时安装，运行时控制已安装插件是否启用，详见 [插件生命周期](plugins.md)。
- 注册插件的操作人负责插件安全性；运行时按可信插件模型设计。
- 站点业务 API 与维护 API 是交付程序的对外契约，管理端通过这些接口完成相应维护。
- 插件的业务实现与后台扩展一起纳入构建，运行时按插件启用状态开放相应管理能力。
- 同一源码可以通过不同入口、构建配置或适配满足两个运行目标；具体数据库、存储和任务执行机制待设计。
- 可维护性需覆盖源码接手、项目定制、插件升级、业务数据及故障恢复；具体保证见总览与各业务文档中的待确认项。

## 3. 首版业务能力

这些是首版可生成、可组装的能力范围，不表示每个交付站点都必须启用全部模块。

| 能力 | 已确认范围 | 详细需求 |
| --- | --- | --- |
| 企业展示 | 提供企业展示模块 | 页面、内容和日常维护方式待细化 |
| 客服 | 对接外部客服服务 | 服务商、入口与业务上下文待细化 |
| 电商 | 单商家 B2C 实物零售，市场可配置；完整商品管理、国内和国际支付、主流物流接入，可拆分模块 | [电商需求基线](commerce.md) 与 [市场和物流](shipping.md)；具体规则和适配器待确认 |
| 用户管理 | 标准用户管理 | [用户管理与 CRM](users-crm.md)；登录方式等待细化 |
| CRM | 可选增强插件，首版完整客户运营，预留销售管理扩展接口 | [用户管理与 CRM](users-crm.md) |

上述用户管理和 CRM 属于交付站点能力，不自动构成管理端自身的账号与客户体系。

完整业务数据导出和跨环境迁移仍需单独确定；提供两个运行目标不等于已经具备一键数据迁移。

## 5. 管理端与站点业务后台的区分

管理端负责需求、代码生成、工程与版本、构建、部署和跨站点维护。站点业务后台必须随源码交付，面向单个站点的业务经营与日常操作，独立于管理端运行。

管理端不是客户侧业务后台，也不作为客户交付软件的一部分。内部团队可按服务约定代为执行维护；已确认客户自行修改交付源码后，不要求支持重新交由管理端继续生成和升级。客户可自行维护其源码版本，源码运行、配置和交接说明仍属于可维护性交付要求。

通过业务后台维护内容、商品、订单、用户、CRM 或已开放配置，不等同于源码修改；该类正常业务操作继续按对应 API 和插件规则进行。

业务后台由通用后台框架和插件注册的管理功能组成，业务内容随启用插件变化。管理端是否额外提供统一的跨站点业务界面仍待确认，该能力不替代交付站点自身的业务后台。

## 6. 候选验收

- 同一份源码部署到两个运行目标，所选业务插件与运行时 API 满足同一契约。
- 交付站点无需代码生成 agent 或管理端生成服务即可提供已部署业务。
- 接手者可按文档修改站点与插件、构建和部署，交付物包含完成这些操作所需的工程信息。
- 已安装插件可以运行时启停；未安装能力只能经工程变更、构建和发布加入。
- 账号、内容、订单、支付及 CRM 按对应模块契约运行，不依赖管理端保存唯一业务事实。
- 开放 API 允许托管服务与其他已授权调用方完成约定的运行时维护。
- 管理端不可用时，仍可通过站点业务后台进行约定的日常操作；插件的管理界面与 API 一并交付。
- 安装、启用、停用插件时，其业务后台入口与操作按约定变化，插件能通过注册扩展通用后台。
- 页面和业务定制可通过主题与插件实现，操作人构建交付站点无需修改核心代码。

后台注册契约、市场配置与交易渠道、双平台基础服务适配与数据交接等问题明确后，补齐最终可执行验收步骤。
