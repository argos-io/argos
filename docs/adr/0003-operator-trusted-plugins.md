# 注册操作人负责插件安全性，系统采用可信插件模型

用户明确要求插件安全性由注册插件的操作人评估和负责。系统因此将注册后纳入构建的插件视为可信代码，不提供平台侧插件安全审查、恶意代码隔离或受限权限沙箱，也不为插件安全引入额外沙箱运行环境。

这一选择使插件执行机制围绕功能组装、运行时启停和交付维护设计。插件 API 与数据归属约定承担可维护性和业务契约职责，不构成约束恶意插件访问宿主资源的安全边界。具体执行技术仍待选择。

站点自身的账号访问规则、支付校验、交易正确性，以及插件异常和任务失败的恢复策略，继续按对应模块契约实现。
