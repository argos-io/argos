# 管理端与站点交付物分别定义，代码生成属于管理端

用户明确提出两套需求：一套是用于生成和管理站点的管理端，另一套是生成的最终站点交付物。允许按需求生成新插件，但生成过程由管理端完成，不由交付程序承担。

管理端负责站点及插件代码的生成、修改与管理，并承担相应构建、发布和托管流程。站点交付物以源码为核心，负责运行站点及已安装插件，通过开放 API 接受约定的维护；不内置用于生成自身代码或新插件的生成流程。

这一边界让两套需求可以分别验收，站点的双运行目标与源码交付不必携带管理端的生成环境。站点交付物必须自带独立业务后台，插件向后台注册对应管理能力，详见 [站点业务后台](../business-admin.md)。

管理端采用 Web 工作台和 agent 执行生成、部署不限定 Cloudflare，且永久仅供内部团队使用，永远不向客户交付或开放使用。客户获得站点交付物及其业务后台；内部团队可以使用管理端按约定提供持续维护。具体 SDK、执行平台、源码存储与版本流程仍待确认。
