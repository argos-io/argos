# 插件构建时安装，运行时控制启用

用户明确要求插件必须在构建中安装，但可以在运行时控制是否启用。采用构建阶段确定插件代码与版本、运行阶段控制已安装能力是否开放的边界，以同时支持源码交付、版本维护和运行中的功能切换。

新增、升级或从交付产物中移除插件，需要重新构建发布；运行时不能安装新插件或切换到构建产物中不存在的代码版本。启停与数据删除分开定义，启用开关不能替代代码版本与数据迁移管理。

## 后续设计问题

- 启停的依赖校验、生效时限、多实例一致性，以及页面、路由、任务和后台扩展的处理。
- 停用期间在途交易、异步回调、持久任务与历史数据的处理。
- 插件信任范围后续已由 [ADR-0003](0003-operator-trusted-plugins.md) 确认：安全性由注册操作人负责，不提供恶意代码沙箱隔离。

具体生命周期方案见 [插件生命周期](../plugins.md)，其中尚未确认的处理策略保留为设计建议。
