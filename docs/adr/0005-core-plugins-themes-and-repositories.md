# 核心独立维护，操作人通过插件和主题组装站点

Argos 的操作人只按需组装插件、创建或编辑插件、创建或编辑主题。主题视为插件的一类，承担页面与视觉定制；核心系统不随单个站点需求调整，管理端的 agent 生成任务也不修改核心代码。

项目在 `/root/src/github.com/argos-io/` 下并列组织三个独立 Git 仓库：`argos`（保留设计）、`core`（核心系统）、`plugins`（插件与主题），各自独立提交和维护远端。核心提供稳定扩展契约，业务插件和主题独立演进，构建交付时固定各自版本；契约不足由独立核心维护流程处理。

这一选择将核心演进与业务资产生成分开，避免生成任务为满足单站点需求修改共享核心。具体包结构、版本发布与依赖交付方式尚待设计，见 [仓库组织](../repositories.md) 与 [主题边界](../themes.md)。
