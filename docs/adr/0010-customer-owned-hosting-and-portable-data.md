# 客户自有 Cloudflare 账户代管，首版支持完整数据双平台恢复

用户在继续收敛首版交付与验收范围时确认两项要求：

- 首版支持完整数据导出，并可恢复到 Cloudflare 或 Node.js，不采用仅保证同平台备份恢复、以后再支持跨平台迁移的范围。
- Cloudflare 托管资源属于客户自有账户，由客户授权团队代管，不采用平台统一账户作为默认托管归属。

本决策补充 [ADR-0001](0001-source-first-delivery.md) 的源码优先与双运行目标要求，将实际数据可接管与恢复纳入首版交付边界。客户可在保有账户控制权的情况下使用代管服务，数据恢复不能依赖内部管理端持有唯一业务事实。

## 后续设计约束

- 核心及所选插件需要完整导出与恢复契约，覆盖站点持有的业务数据、关系、文件及恢复必需状态；不能只给出前台 CSV 或指向源存储的链接。
- 两个运行目标都需要真实的目标存储恢复验证；同一源码能运行不替代数据迁移验收。
- 云账户授权与站点后台/维护 API 授权分别设计。具体授权接入、资源映射、费用、代管责任及撤销流程继续细化。
- 数据包内容、一致性切点、第三方依赖、身份/密钥配置交接、在途业务与恢复流程见 [站点交付物第 8 节提案](../site-deliverable.md#8-客户账户托管与完整数据交付)。这些细化建议尚未整体接受，不承诺一键、无停机或任意历史版本自动转换。
- 首版功能与验收候选清单见 [站点交付物第 7 节](../site-deliverable.md#7-首版可交付功能与验收基线提案)；本决策不自动批准各业务模块的所有候选功能、服务商或运维服务等级。

本轮只更新设计文档，未创建或修改任何云账户、代管授权、部署资源或客户数据。
